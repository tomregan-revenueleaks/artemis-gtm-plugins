# Artemis GTM — Claude Code Plugin Marketplace

Generated build (own marketplace). Do not edit by hand — regenerate with `node scripts/build-plugins.cjs`.

## Install

```
/plugin marketplace add tomregan-revenueleaks/artemis-gtm-plugins
/plugin install gtm-audit@artemis-gtm
```

The free **gtm-audit** plugin is the one-install GTM Audit agent: the deep guided audit plus all six ROI / analyzer calculators as on-demand modules.
